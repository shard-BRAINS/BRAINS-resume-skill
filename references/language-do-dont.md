# ND-Affirmative Language: Do / Don't Reference

**Purpose:** Every BRAINS Resume Skill workflow consults this document when proposing or reviewing wording in a resume, cover letter, or related document. It is a guidance resource, not an enforcement mechanism. The user's preference always wins. If you — the person using this skill — tell the skill to use different language than what appears below, the skill follows your lead.

---

## 1. How to use this document

Use this document as a prompt, not a rule book. When the skill suggests replacing a phrase, it draws on this reference to explain why — but "why" is not "must." Identity-first language is the default (for example, "autistic person" rather than "person with autism"), because that reflects the most widely expressed preference of autistic communities. If you prefer person-first, or a different framing entirely, say so once and the skill applies your preference consistently for the rest of the session.

---

## 2. Do / Don't Table

| Don't use | Do use instead | Why |
|---|---|---|
| suffers from autism | is autistic | Pathologising language; autism is not a disease or a source of suffering by definition. |
| afflicted with ADHD | has ADHD / is an ADHDer | "Afflicted" implies victimhood; the person defines their own relationship to their diagnosis. |
| struggles with sensory issues | manages sensory differences | "Struggles" frames a neutral characteristic as a deficit. |
| confined to a wheelchair | is a wheelchair user / uses a wheelchair | Wheelchairs are mobility aids, not confinements. |
| wheelchair-bound | wheelchair user | Same reason as above; "bound" erases the person's agency. |
| person with autism | autistic person | Community preference is identity-first; use person-first only when the individual requests it. |
| person with ADHD | ADHDer / person with ADHD (if they prefer) | Follow individual preference; the skill defaults to identity-first. |
| high-functioning autistic | omit the functioning label; describe the support context if relevant | "High-functioning" implies a hierarchy of worth; it also erases real support needs. |
| low-functioning autistic | omit the functioning label; describe the support context if relevant | "Low-functioning" devalues people and over-predicts limitation. |
| special needs | accessibility needs / support needs | "Special needs" is infantilising and imprecise; name the actual need where possible. |
| differently abled | disabled / autistic / [specific identity the person uses] | Euphemisms can obscure real barriers and are often rejected by disabled communities. |
| passionate about X | [concrete instance + outcome]: "led X project, resulting in Y" | Vague passion claims are bias-coded filler; ATS and human screeners both reward specifics. |
| results-driven professional | [state the actual result]: "reduced processing time by 30%" | "Results-driven" signals nothing; a real result does. |
| excellent communicator | [evidence]: "presented findings to 40-person team quarterly" | Soft-skill adjectives without evidence are screened out; specifics stay in. |
| team player | [evidence]: "co-authored documentation with a cross-functional team of 6" | Same reason; every candidate calls themselves a team player. |
| strong work ethic | [evidence]: "delivered all milestones on schedule across 3 consecutive quarters" | Demonstrate the ethic; don't claim it. |
| chairman | chair / chairperson | Gender-neutral is the professional default for titles. |
| manpower | workforce / staffing / personnel | Gender-neutral and more precise. |
| man-hours | person-hours / staff-hours / hours of work | Same reason as manpower. |
| he or she (generic) | they / the person / the candidate | Singular "they" is standard; "he or she" excludes non-binary people. |
| tone-deaf approach | out-of-touch approach / approach that missed the mark | "Tone-deaf" appropriates a disability-related experience as a general insult. |
| falls on deaf ears | goes unheeded / was not acted on | Ableist idiom; replace with a literal phrase. |
| blind to the problem | unaware of the problem / overlooked the problem | Ableist idiom; use a literal alternative. |
| lame excuse | weak excuse / unconvincing excuse | "Lame" as an insult derives from disability language. |
| crazy deadline | very tight deadline / unrealistic deadline | "Crazy" used as a pejorative stigmatises mental health conditions. |
| sanity check | review / verification / consistency check | Frames the check as a test for mental instability; use a functional description. |
| OCD about detail | meticulous / precise / detail-focused | Misappropriates a clinical diagnosis; describe the actual quality instead. |
| stands on its own two feet | self-sufficient / independently viable | Ableist metaphor; a literal phrase is clearer and more inclusive. |
| crippled by technical debt | severely hampered by technical debt / weighed down by technical debt | "Crippled" as a negative descriptor appropriates disability experience. |

## 3. Edge cases

**When the user describes themselves using "Don't" column language.** If someone says "I want to describe myself as a person with autism" or "that's my language," follow their lead without correction or negotiation. This document defines the skill's defaults; it does not override individual self-identification. The skill may note once, briefly, what the community-default preference is — then it applies the user's preference and moves on.

**When an organisation's official name contains outdated or flagged language.** Use the official name as published, exactly as written. If a credential, employer, or publication uses language this document would otherwise flag, the skill reproduces that name accurately — accuracy over consistency. The skill does not silently alter proper nouns. If the user wants to note the tension, the skill can help draft a contextual note.

**When a job description uses biased language and the user is mirroring it strategically.** Some users deliberately echo a job description's phrasing (including potentially biased terms) to improve ATS keyword matching. This is a legitimate tactic. When this situation arises, the skill offers the mirroring option alongside a plain-language alternative, and notes the trade-off: mirroring may improve automated screening; plain language may read more naturally to a human screener. The user decides.

---

## 4. What this document does not do

This document is a wording-craft reference for resume content. It is **not** a slur list, **not** an exhaustive catalogue of every possible bias pattern in the English language, and **not** legal or clinical language guidance. It does not address discrimination law, reasonable-adjustments frameworks, medical terminology, or formal accessibility standards — those require qualified professional advice. Its scope is limited to the kinds of phrases that appear in resumes, cover letters, and job descriptions, and the practical effect those phrases have on how a candidate is read by screeners, human or automated.
